# AIES-
Advanced Image Manipulation Software is one of the most compatible image manipulation tools on the web. This is highly portable and shareable to various devices. The small package packs a dynamic editing experience for editing on the fly.
 This software's pre-alpha has been published officially to the wide web 8/ AUGUST/ 2026. Pre-alpha's former commitment was withing a range of the following versions:
 1.0,1.1,1.2,1.3,1.4,1.5,1.6
 You can boot this application on any device with a supported web driver (Basically everything from you smartphone to a refrigerator)
 The code uploaded can be easily modified by converting the contents of the pre-alpha releases into a .txt file. After that, create necessary tweaks while keeping the software stable. Malware infected/ corrupted unofficial releases shall be flagged and potentially taken down.
